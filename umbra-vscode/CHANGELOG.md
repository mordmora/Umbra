# Change Log

All notable changes to the "Umbra Language" extension will be documented in this file.

## [1.0.0] - 2026-01-05

### Added
- Initial release
- Syntax highlighting for `.umbra` files
- Support for all Umbra keywords and types
- Comment highlighting (`//`)
- String and character literal highlighting
- Number highlighting (integers and floats)
- Operator highlighting
- Function definition and call highlighting
- Auto-closing pairs for brackets, braces, and quotes
- Code folding support
- Indentation rules
